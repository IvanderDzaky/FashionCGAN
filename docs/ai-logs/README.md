# Panduan Log Interaksi AI

Gunakan `session-template.md` lintas OpenCode, Hermes, ChatGPT, Claude, Gemini, dan platform AI lain. Isi hanya hal yang benar-benar terjadi; jangan merekonstruksi prompt, respons, hasil tes, atau tautan yang tidak tersedia.

## Alur

1. Salin template menjadi `docs/ai-logs/YYYY-MM-DD-member-name-topic.md`.
2. Catat platform/model dan target sebelum atau sesudah sesi, tanpa mengarang detail yang terlupa.
3. Simpan ekspor/tautan percakapan asli di `evidence/member-N/`; cantumkan lokasi relatif dalam log. Hormati kebijakan privasi platform dan hapus kredensial sebelum menyimpan bukti.
4. Catat hasil pengujian dengan perintah tepat dan status nyata. Gunakan “belum dijalankan” jika belum diuji.
5. Catat file yang benar-benar berubah serta error/solusi yang benar-benar dialami.

## Bukti

- `evidence/ivander-dzaky-khairullah/`: bukti Ivander Dzaky Khairullah.
- `evidence/muhammad-ragil/`: bukti Muhammad Ragil.
- `evidence/silmi-sila-nia-uma/`: bukti Silmi Sila Nia Uma.
- Format bebas: ekspor Markdown/HTML/TXT atau tautan percakapan dengan akses tim. Tambahkan nama platform/model pada nama berkas bila berguna.
- Jangan menyimpan API key, token, data pribadi sensitif, atau percakapan yang tidak berhak dibagikan.
